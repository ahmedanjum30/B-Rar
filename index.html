Archives, extracted. Fast.

B-Rar opens ZIP, RAR, 7z and tar archives and extracts them faster than WinRAR and 7-Zip, using every core of your PC. Right-click any archive in File Explorer, or look inside first and take out just what you need.

Everything an extractor should do

Fast where it counts, out of your way everywhere else.

Every core at once

Files are extracted in parallel, so a big archive finishes in a fraction of the time. B-Rar has its own RAR5 decoder and uses libdeflate for ZIP.

Right-click menu

In the short Windows 11 menu: Open in B-Rar, Extract files..., Extract to "folder\", Extract here and Test archive.

Look inside first

Browse an archive's folders, search it, open a single file, and extract only the files and folders you pick.

Passwords

Asks when an archive is encrypted, including archives with encrypted file names: AES ZIP, ZipCrypto, 7z and RAR.

Archives in parts

RAR volumes (.part1.rar, .r00) and split archives (.001). Start from any part; a missing part is named.

Safe by default

Asks before replacing a file (replace, skip or keep both), keeps files inside the folder you chose, and checks every file's checksum.

Opens what you download

Every common archive format, including the ones Windows can't open on its own.

  • ZIPDeflate, Deflate64, BZip2, LZMA, XZ, Zstandard, PPMd; AES and ZipCrypto
  • RARRAR 4 and RAR 5, solid, encrypted and multi-volume
  • 7zLZMA, LZMA2, BZip2, Deflate, PPMd, Zstandard, AES
  • tar.tar, .tar.gz, .tar.xz, .tar.zst, .tar.bz2, and single .gz, .xz, .zst, .bz2 files

From the command line too

The same engine, from any terminal: B-Rar is on your PATH once it's installed.

# extract to a folder named after the archive
B-Rar x archive.rar
# somewhere else, without asking about existing files
B-Rar x archive.zip -o D:\out -y
# only some files and folders
B-Rar x archive.7z docs photos/2026
# list, or check every file without writing anything
B-Rar l archive.7z
B-Rar t archive.7z

Questions

Didn't find yours? Open an issue on GitHub.

Is B-Rar free?

Yes, for personal and other non-commercial use, with every feature included. There are no ads, no trial and no paid version. If you'd like to support it, there's Patreon.

Can B-Rar create archives?

No. B-Rar extracts archives; it doesn't make them. That's what lets it focus on being fast at the part you do most.

Why is it faster than WinRAR and 7-Zip?

It extracts many files at once, on every core, and writes them in the background while it keeps decoding. RAR5 archives use B-Rar's own decoder, which is faster than 7-Zip's even on a single core, and ZIP uses B-Rar's own Deflate decoder, faster than libdeflate on large files, which even splits a single big file across all your cores.

Where's the right-click menu?

Right-click any archive in File Explorer and pick B-Rar. On Windows 11 it's under Show more options; the Microsoft Store version (coming soon) puts it in the short menu.

Windows says "Windows protected your PC"

Click More info, then Run anyway. B-Rar isn't code-signed yet, so Windows doesn't know the publisher. The installer is built from the public source by the project's release workflow; you can check it against SHA256SUMS.txt on the release page.

Is it in the Microsoft Store? Can I install it with winget?

Coming soon. The Store version adds B-Rar to the short Windows 11 right-click menu and updates through the Store, and winget install B-Rar will install it. Until then, the installer above updates itself: B-Rar says when a new version is out.

Does it send my data anywhere?

No. B-Rar only asks GitHub whether a newer version is out, and downloads it when you click Update (the Microsoft Store version doesn't connect to the internet at all). See the privacy policy.

Can I use it at work?

B-Rar's license (PolyForm Noncommercial) allows personal use and use by charities, schools and public institutions, but not commercial use. For commercial use, get in touch on GitHub.
